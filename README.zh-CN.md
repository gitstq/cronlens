# CronLens

**一眼看清你的 cron 任务。**

零依赖、可离线的浏览器 Cron 表达式可视化调试器。输入一个 Cron 表达式，即可实时看到：人类可读的描述、未来运行时间、每周热力图和每月日历。一切都在你的浏览器中运行。

## 功能特性

- **实时解析** — 支持 5 段和 6 段（含秒）Cron 表达式，以及 `@` 快捷方式（`@daily`、`@hourly`、`@reboot` 等）。
- **人类可读描述** — 自动生成自然语言摘要，支持英文、简体中文和繁体中文。
- **下次运行预测** — 精确计算本地时区下的未来 N 次运行时间。
- **每周热力图** — 7×24 网格，一眼看清任务在一周内的触发分布。
- **每月日历** — 浏览任意月份，高亮显示所有匹配日期。
- **字段拆解** — 表达式的每个字段被单独解析并标注说明。
- **预设库** — 内置 30+ 个常用 Cron 表达式，一键加载。
- **复制与分享** — 复制表达式，或通过链接分享当前视图。
- **深色 / 浅色主题** — 一键切换，适配你的使用环境。
- **本地优先、隐私安全** — 100% 客户端运行，零网络请求，数据不出设备。

## 支持的语法

| 特性 | 示例 | 含义 |
| --- | --- | --- |
| 通配符 | `*` | 每个值 |
| 列表 | `1,15,30` | 多个值 |
| 区间 | `9-17` | 值的范围 |
| 步长 | `*/5` 或 `10-40/5` | 每 N 个值 |
| 最后一天 | `L` | 当月最后一天（日字段） |
| 最后星期几 | `5L` | 当月最后一个周五（周字段） |
| 最近工作日 | `15W` | 离 15 号最近的工作日（日字段） |
| 第 N 个星期几 | `3#2` | 第二个周二（周字段） |
| 名称 | `JAN-DEC`、`SUN-SAT` | 月份 / 星期名称 |
| 快捷方式 | `@daily`、`@hourly`、`@reboot` | 常用预设 |

> 当日字段与周字段同时受限时，遵循标准 Vixie-cron 的 OR 语义。

## 快速开始

CronLens 是纯静态网页应用，无需构建、无需安装、零依赖。

```bash
# 方式一：直接用现代浏览器打开 index.html
open index.html

# 方式二：本地启动静态服务
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

也可以直接通过 GitHub Pages 在线使用：<https://gitstq.github.io/cronlens/>

## 使用方法

1. 在输入框中输入 Cron 表达式（试试 `0 9 * * 1-5`）。
2. 描述、下次运行时间、每周热力图和每月日历会实时更新。
3. 点击任意预设标签，快速加载常用调度。
4. 使用「复制」复制表达式，或使用「分享」获取当前视图链接。
5. 在顶部栏切换语言（EN / 简 / 繁）和主题。

## 示例

| 表达式 | 含义 |
| --- | --- |
| `*/5 * * * *` | 每 5 分钟 |
| `0 9 * * 1-5` | 工作日 09:00 |
| `0 0 1 * *` | 每月 1 日午夜 |
| `0 0 L * *` | 每月最后一天午夜 |
| `0 9 * * 1` | 每周一 09:00 |
| `0 22 * * 5` | 每周五 22:00 |
| `0 0 1 1 *` | 每年 1 月 1 日 |
| `30 8 * * 1-5` | 工作日 08:30 |
| `0 9,12,15 * * *` | 09:00、12:00、15:00 |
| `*/30 * * * * *` | 每 30 秒（6 段） |
