# CronLens

**一眼看清你的 cron 任務。**

零依賴、可離線的瀏覽器 Cron 表達式視覺化除錯器。輸入一個 Cron 表達式，即可即時看到：人類可讀的描述、未來執行時間、每週熱力圖和每月日曆。一切都在你的瀏覽器中執行。

## 功能特性

- **即時解析** — 支援 5 段和 6 段（含秒）Cron 表達式，以及 `@` 快捷方式（`@daily`、`@hourly`、`@reboot` 等）。
- **人類可讀描述** — 自動產生自然語言摘要，支援英文、簡體中文和繁體中文。
- **下次執行預測** — 精確計算本地時區下的未來 N 次執行時間。
- **每週熱力圖** — 7×24 網格，一眼看清任務在一週內的觸發分佈。
- **每月日曆** — 瀏覽任意月份，高亮顯示所有符合日期。
- **欄位拆解** — 表達式的每個欄位被單獨解析並標註說明。
- **預設庫** — 內建 30+ 個常用 Cron 表達式，一鍵載入。
- **複製與分享** — 複製表達式，或透過連結分享目前檢視。
- **深色 / 淺色主題** — 一鍵切換，適應你的使用環境。
- **本地優先、隱私安全** — 100% 用戶端執行，零網路請求，資料不出裝置。

## 支援的語法

| 特性 | 範例 | 含義 |
| --- | --- | --- |
| 萬用字元 | `*` | 每個值 |
| 清單 | `1,15,30` | 多個值 |
| 區間 | `9-17` | 值的範圍 |
| 步長 | `*/5` 或 `10-40/5` | 每 N 個值 |
| 最後一天 | `L` | 當月最後一天（日欄位） |
| 最後星期幾 | `5L` | 當月最後一個週五（週欄位） |
| 最近工作日 | `15W` | 離 15 號最近的工作日（日欄位） |
| 第 N 個星期幾 | `3#2` | 第二個週二（週欄位） |
| 名稱 | `JAN-DEC`、`SUN-SAT` | 月份 / 星期名稱 |
| 快捷方式 | `@daily`、`@hourly`、`@reboot` | 常用預設 |

> 當日欄位與週欄位同時受限時，遵循標準 Vixie-cron 的 OR 語義。

## 快速開始

CronLens 是純靜態網頁應用，無需建置、無需安裝、零依賴。

```bash
# 方式一：直接用現代瀏覽器開啟 index.html
open index.html

# 方式二：本地啟動靜態服務
python3 -m http.server 8080
# 然後造訪 http://localhost:8080
```

也可以直接透過 GitHub Pages 線上使用：<https://gitstq.github.io/cronlens/>

## 使用方法

1. 在輸入框中輸入 Cron 表達式（試試 `0 9 * * 1-5`）。
2. 描述、下次執行時間、每週熱力圖和每月日曆會即時更新。
3. 點擊任意預設標籤，快速載入常用排程。
4. 使用「複製」複製表達式，或使用「分享」取得目前檢視連結。
5. 在頂部欄切換語言（EN / 簡 / 繁）和主題。

## 範例

| 表達式 | 含義 |
| --- | --- |
| `*/5 * * * *` | 每 5 分鐘 |
| `0 9 * * 1-5` | 工作日 09:00 |
| `0 0 1 * *` | 每月 1 日午夜 |
| `0 0 L * *` | 每月最後一天午夜 |
| `0 9 * * 1` | 每週一 09:00 |
| `0 22 * * 5` | 每週五 22:00 |
| `0 0 1 1 *` | 每年 1 月 1 日 |
| `30 8 * * 1-5` | 工作日 08:30 |
| `0 9,12,15 * * *` | 09:00、12:00、15:00 |
| `*/30 * * * * *` | 每 30 秒（6 段） |

## 專案結構

```
cronlens/
├── index.html            # 單頁入口
├── css/
│   └── style.css         # 樣式（深色/淺色主題、響應式）
├── js/
│   ├── cron-parser.js    # 零依賴 Cron 解析與計算引擎
│   ├── i18n.js           # 多語言描述（en/zh-CN/zh-TW）
│   ├── presets.js        # 精選預設庫
│   └── app.js            # UI 邏輯與渲染
├── tests/
│   └── run-tests.cjs     # 單元測試（Node，無依賴）
└── package.json
```
